I completed a four-month internship at [EQUANS](https://www.equans.fr/) between September 15,  2025 and January 30, 2026.

Originally brought on to build an open-source AI agent using Ollama for CI/CD optimization, internal governance requirements required a quick shift in strategy. Instead of stalling, I redirected my efforts toward maximizing the tools already available:

- Demystifying GitHub Copilot: Led internal sessions covering advanced Copilot capabilities to streamline developer workflows.
- Prompt Engineering for CI/CD: Designed structured prompt templates to assist with automated delivery tasks.
- Repository Architecture: Re-organized the company's admin GitHub repository for better scalability and clearer governance.
